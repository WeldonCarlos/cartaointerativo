# Cartão Interativo · Base React

Repositório inicial de estudo em React criado com Create React App.

## O que o projeto apresenta

- Componente raiz e estilos da aplicação.
- Configuração inicial de testes com Testing Library.
- Scripts de desenvolvimento e build.

## Tecnologias

React · JavaScript · CSS · Create React App · Testing Library

## Executar localmente

```bash
git clone https://github.com/WeldonCarlos/cartaointerativo.git
cd cartaointerativo
npm install
npm start
```

Abra o endereço informado no terminal.

## Comandos disponíveis

| Comando | Uso |
| --- | --- |
| `npm start` | `react-scripts start` |
| `npm run build` | `react-scripts build` |
| `npm test` | `react-scripts test` |

Os scripts são os definidos em `package.json`; sua presença não indica que foram executados nesta revisão de documentação.
